# EventB2C Web Design Prototype

Static HTML/JSX prototype of the B2C web application design, exported from Claude Artifacts.

## Running

Serve the files with any local HTTP server. For example, using Python:

```bash
cd documentation/designs/web-b2c/EventB2CWeb
python3 -m http.server 8080
```

Then open http://localhost:8080 in your browser.

### Alternative servers

```bash
# Node.js (npx, no install needed)
npx serve -p 8080

# PHP
php -S localhost:8080
```

## Stopping

Press `Ctrl + C` in the terminal where the server is running.
