# Wydarzka — B2C Marketing Plan

> **Target:** Consumer users (event-goers) in Polish cities
> **Goal:** 1,000+ events on the map, strong D7/D30 retention, organic growth loop
> **Markets:** Poznan (primary), Krakow, Warszawa, Wroclaw, Gdansk, Lodz, Katowice

---

## 2. Pre-Launch (Weeks 10-12)

### 2.1 SEO Foundations (Web B2C)

Web B2C launches with SSR pages optimized for search from day one. This is the single highest-ROI channel long-term.

**Target keywords (PL + EN):**
- "wydarzenia [miasto]" / "events [city]" (e.g., "wydarzenia Poznan")
- "co robic w weekend [miasto]" / "what to do this weekend [city]"
- "koncerty [miasto] dzisiaj" / "concerts [city] today"
- "imprezy [miasto]" / "parties [city] tonight"
- "wydarzenia dla dzieci [miasto]" / "kids events [city]"
- "festiwale [miasto] 2026"

**Pages that index:**
- City landing pages: `/poznan`, `/krakow`, `/warszawa` (7 cities)
- Category pages: `/poznan/music`, `/poznan/nightlife`, `/krakow/food-drink`
- Temporal pages: `/poznan/this-weekend`, `/poznan/today`
- Event detail pages with JSON-LD structured data (Google Event rich results)
- Venue profile pages with Place schema

**Actions:**
- [ ] Prepare sitemap.xml with all city/category combinations before launch
- [ ] Submit to Google Search Console on day 1
- [ ] Validate all pages with Google Rich Results Test
- [ ] Set up Google Search Console monitoring for impressions/clicks
- [ ] Create a blog section at `/blog` for city guides (post-launch, Month 2)

### 2.2 Social Media Setup

**Platforms (priority order):**

1. **Instagram** — primary visual channel
   - Handle: `@wydarzka.pl`
   - Content: event highlights, venue spotlights, weekend roundups
   - Reels: 15-30s event teasers, "best events this weekend" compilations
   - Stories: daily "what's happening today" polls, countdowns to big events

2. **TikTok** — discovery and virality
   - Handle: `@wydarzka.pl`
   - Content: "hidden gem" events, "things to do in [city]" format
   - Trend-jacking: local event reactions, "POV: you discover [event]"

3. **Facebook** — community building + events
   - Page: Wydarzka
   - Groups: "Wydarzka [City]" for each launch city (start with Poznan)
   - Cross-post events to Facebook Events for additional reach

**Actions:**
- [ ] Create accounts on Instagram, TikTok, Facebook (2 weeks before launch)
- [ ] Prepare 2 weeks of content backlog (15-20 posts)
- [ ] Design branded templates in Canva/Figma for consistent visual identity (violet palette, Inter font)
- [ ] Follow and engage with local venues, event pages, and city accounts

### 2.3 Landing Page & Waitlist

Before the app is live, deploy a simple landing page at `wydarzka.dev`:

- Hero: "Discover events in your city" with city selector
- Preview: map screenshot with pins, 3-4 sample event cards
- Email capture: "Get notified when we launch in [your city]"
- App Store / Google Play "Coming Soon" badges
- Social proof: "1,000+ events already mapped"

**Actions:**
- [ ] Deploy landing page at `wydarzka.dev` (Week 10)
- [ ] Set up email list (Resend or Mailchimp free tier)
- [ ] Run a small Instagram/Facebook ad campaign targeting Poznan (50-100 PLN budget) to build initial waitlist

### 2.4 Pre-Launch Venue Outreach

> This feeds the supply side, which is critical for B2C value.

- [ ] Compile list of 50 target venues in Poznan (bars, clubs, theaters, galleries, concert halls)
- [ ] Personal outreach to 10 key venues (phone calls, in-person visits)
- [ ] Offer: "Your venue is already on Wydarzka with [X] followers. Claim it for free to manage your events."
- [ ] Provide venues with branded "Find us on Wydarzka" window stickers and table tents

## 4. Ongoing Growth (Month 1-3)

### 4.1 Content Marketing Calendar

**Weekly cadence:**

| Day | Content | Platform |
|-----|---------|----------|
| Monday | "Week ahead" — top 5 events this week | Instagram Story, Facebook |
| Wednesday | Venue spotlight — interview/feature of a local venue | Instagram Post + Reel |
| Thursday | "Weekend plans" — curated picks for the weekend | Instagram, TikTok, Facebook |
| Friday | "Tonight in [city]" — real-time event highlights | Instagram Story |
| Saturday | User-generated content reshares, event photos | Instagram Story |
| Sunday | "What did you discover?" — engagement post | Instagram, TikTok |

**Monthly:**
- City guide blog post: "Top 10 [category] events in [city] this month" (SEO play)
- Newsletter to email subscribers: monthly event highlights + new features

### 4.2 Organic Growth Loops

These are built into the product and require no ad spend:

**Loop 1: Share -> Web -> App Install**
```
User finds event in app -> Shares link to WhatsApp/Instagram
-> Friend opens link -> Lands on Web B2C event page (full SEO context)
-> Smart banner: "Save this event in the app" -> App Store install
```

**Loop 2: Community Scout -> Content -> Discovery**
```
User submits event tip ("Know about an event?" FAB)
-> Admin approves -> Event appears on map
-> "Tipped by @username" attribution visible
-> User shares their discovery -> Social proof -> More tips
```

**Loop 3: Venue Follow -> Push -> Return**
```
User follows venue -> Venue posts new event
-> Push notification: "New event at [venue]!"
-> User opens app -> Discovers more events -> Follows more venues
```

**Loop 4: SEO -> Web -> App**
```
Google search: "koncerty Poznan weekend"
-> Lands on /poznan/music (SSR, rich results)
-> Browses events -> Smart banner -> App install
```

### 4.3 App Store Optimization (ASO)

**App Store (iOS):**
- Title: "Wydarzka — Events Near You"
- Subtitle: "Find events in your area"
- Keywords: events, concerts, nightlife, things to do, weekend, nearby, Poznan, Krakow, Warszawa
- Screenshots: map view, event detail, venue profile, category filters
- Description: bilingual (PL primary, EN secondary)

**Google Play:**
- Title: "Wydarzka — Discover Events Nearby"
- Short description: "Find concerts, parties, art, food events and more on one map"
- Feature graphic: map with colored pins + event cards
- Screenshots: same as iOS, adapted for Android frame

**Actions:**
- [ ] A/B test screenshots (map-first vs. event-card-first)
- [ ] Monitor keyword rankings weekly
- [ ] Respond to all reviews within 24h (builds trust + signals to algorithm)
- [ ] Update screenshots each month with seasonal events

### 4.4 Community Building

**Wydarzka Scouts Program:**
- Users who submit event tips earn "Scout" and "Top Scout" badges
- Monthly leaderboard: "Top Scouts in [city]" — featured on social media
- Top Scouts get early access to new features and a "Scout" badge on their profile
- Goal: 50 active Scouts across all cities by Month 3

**University Ambassadors (Month 2-3):**
- Recruit 1-2 student ambassadors per major university in each city
- Role: share events on campus channels, submit tips, provide feedback
- Incentive: featured profile, early access, potential referral bonus post-monetization

## 7. City Expansion Playbook

When expanding to a new city, follow this checklist:

### Pre-launch (2 weeks before)
- [ ] Aggregation pipeline populated with 200+ events in the city
- [ ] 10 venue profiles with photos and descriptions
- [ ] City landing page live on Web B2C (`/[city]`)
- [ ] Local social media groups identified (Facebook groups, Reddit, student groups)
- [ ] 3-5 local micro-influencers identified and contacted
- [ ] Local media contacts compiled (city blogs, radio stations)

### Launch
- [ ] Social media announcement: "Wydarzka is now in [city]!"
- [ ] Post in all identified local groups and communities
- [ ] Email subscribers in the city (from waitlist or IP-based targeting)
- [ ] Instagram/Facebook ad campaign targeting the city (200-500 PLN/week for 2 weeks)
- [ ] Venue outreach: top 20 venues contacted for claim

### Post-launch (Month 1)
- [ ] Monitor event density (target: zero-result search < 10%)
- [ ] Engage with first users — respond to feedback, feature their discoveries
- [ ] Publish "Top events in [city]" blog post
- [ ] Recruit local Scout ambassadors
