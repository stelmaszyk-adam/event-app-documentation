# Scenario 4 — "Zapisz. Wyślij. Idziemy." (St. Martin's Day & Christmas Season, Save/Share Loop)

> Part of the B2C promotional scenarios set. Overview, comparison and rollout: [00-overview.md](00-overview.md).
> Lead feature: **Save / Share** (public event links) · Channel type: **built-in growth loop** (real-world trigger: St. Martin's Day on 11 November and the pre-Christmas season in Poznań)

## 1. Name

- **Internal name:** `marcinki-share-loop`
- **Headline (PL):** „Zapisz. Wyślij. Idziemy.”
- **EN:** "Save it. Send it. We're going."

## 2. Target segment and insight

**"The planner" in a friend group or family, 22–40 (overlapping urban explorers and culture enthusiasts).** Around big local days like **Imieniny ulicy Święty Marcin (11.11)** and the December markets, there's so much on that the plan gets lost in the group chat. Someone posts a screenshot, nobody remembers the time, and on the day everyone asks "gdzie to było?".

## 3. Core idea

We turn the busiest local moment of autumn into a sharing moment. We publish curated "save and send" guides to St. Martin's Day and the Christmas season, and every item is a **real Wydarzka event link**. The call to action isn't "install", it's **"wyślij to osobie, z którą idziesz"**. Each shared link opens a public web event page for the friend, with a smart banner to the app. Every share is a free acquisition touchpoint.

## 4. User journey

1. **First contact:** an IG carousel or Facebook post, "11.11 w Poznaniu: zapisz, zanim zapomnisz", or a link sent by a friend in Messenger or WhatsApp.
2. **Web visit → install:** the link opens the **public web event page** (time, place, map, description) with no login. The smart banner offers "Zapisz w aplikacji", which leads to the store.
3. **First open:** the app opens on the map. The user finds the event (or gets it via the deep link, if supported) and taps **Save**.
4. **Aha moment:** they tap **Udostępnij** on 2–3 more events, and the whole day's plan goes to the group chat as clean links instead of screenshots. Friends open them without needing the app.
5. **Return visit:** on the day, the user opens **saved events**, taps **Nawiguj** to get there, and later in the evening checks the map for what else is nearby. In December the same group comes back for the "Święta w Poznaniu" guide.

**Loop:** Save → Share link → friend lands on web event page → smart banner → install → friend saves and shares their own plan.

## 5. Channels and formats

| Format | Where | Notes |
|---|---|---|
| IG carousel (8–10 slides): "11.11 w Poznaniu — zapisz i wyślij" | Wydarzka IG + FB; collab with 2–3 local city/food accounts (**paid or barter collabs clearly labelled "współpraca"**) | Each slide = one event, with the link in bio / Stories link sticker |
| 15s Reel "Plan w 3 kliknięcia" | IG Reels, TikTok | Shows the Save → Share → group chat flow |
| Stories with link stickers | IG Stories on 9–11 November and each December weekend | One Story per event, each linking directly to its web event page |
| Web guide page / blog post | wydarzka.dev (city page or post) | Doubles as SEO support for [05](05-nowy-w-miescie-seo.md) |
| Small boost | Best-performing carousel, Poznań 22–40 | Only after it performs organically |

**Pre-flight product check (before 1 November):** confirm that shared links carry `utm_source=share` (or an equivalent referrer) and that the smart banner shows on event pages. Without these we can't measure the loop.

## 6. Sample creative (Polish)

### A. IG carousel — "11.11 w Poznaniu"

- **Slide 1 (cover):** *„11 listopada w Poznaniu. Zapisz, zanim zapomnisz. Wyślij, zanim ktoś zaplanuje coś innego.”* — Święty Marcin street in autumn light, violet overlay.
- **Slides 2–8:** one event per slide, with the category colour, time, place and a one-line hook, e.g. *„14:00 · Korowód świętomarciński · ul. Święty Marcin — Zajmij miejsce wcześniej, dzieci będą zachwycone.”* (Only real, verified events from the app.)
- **Slide 9:** screenshot of an event detail with the **Zapisz** and **Udostępnij** buttons highlighted. *„Wszystkie te wydarzenia masz w Wydarzce. Zapisz jednym kliknięciem, wyślij znajomym jako link — otworzą bez aplikacji.”*
- **Slide 10:** *„Z kim idziesz? Oznacz tę osobę 👇”*

**Caption:**
> Rogale to jedno, ale 11.11 w Poznaniu dzieje się dużo więcej 🥐✨
> Przygotowaliśmy plan dnia — od porannego korowodu po wieczorne koncerty.
> Zapisz post, a konkretne wydarzenia zapisz w Wydarzce i wyślij ekipie. Nikt już nie zapyta „o której to było?”.

### B. 15s Reel script — "Plan w 3 kliknięcia"

| Time | Scene | On-screen text / VO |
|---|---|---|
| 0–3s | Group chat: „to co robimy 11.11?” → someone sends a blurry screenshot of a poster. Reply: „a gdzie to jest?” | Text: **Screenshoty nie są planem.** |
| 3–7s | Screen recording: Wydarzka map filtered to the St. Martin's Day date, an event opens, tap **Zapisz** (heart animation). | VO: „Zapisz…” |
| 7–11s | Tap **Udostępnij** → Messenger → the link preview in the chat shows the event page. Reply: „idę!”, „biorę dzieci”. | VO: „…wyślij…” |
| 11–15s | 11 November: people on a festive street, a phone showing **Nawiguj** on a saved event. End card. | VO: „…idziemy.” Text: **Zapisz. Wyślij. Idziemy. — Wydarzka** |

## 7. Timing and city

- **City:** **Poznań.** St. Martin's Day is uniquely Poznań and gives us a strong local hook for launch.
- **When:** guide goes live **3–4 November**, Stories push **9–11 November**. The "Święta w Poznaniu" edition (Christmas markets, concerts, family events) runs **late November to 23 December**. Other cities reuse the format for their own big local days.

| Item | PLN |
|---|---|

| Boost of the Christmas edition | 200–300 |

## 9. KPIs

| Metric | Target (Nov–Dec) |
|---|---|
| **Primary: installs attributed to shared links** | 250–400 |
| Shares per active user during campaign weeks | ≥ 0.3 (i.e. roughly 1 in 3 active users shares an event) |
| Saves per active user in campaign weeks | ≥ 1.5 |
| *Supporting:* web event page visits from shared links | 3,000+ |

## 10. Risks and mitigation

- **Most likely failure:** people save the Instagram post instead of the events and never touch the app's Share button, so the loop doesn't start and we just get a nice-performing IG post.
- **Mitigation:** make every item one tap from a real web event page (Story link stickers per event, not only "link in bio"). Make the web page itself the thing people share, since friends don't need the app to open it. Show the Share flow explicitly in the Reel. Watch `utm_source=share` traffic daily from 9 November. If it's flat, move the boost budget to Stories with direct event links.
